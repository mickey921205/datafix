# DataFix v0.2.0

DataFix v0.2.0 expands the local-first cleaner beyond delimited text with Excel support and adds an explicit duplicate-review workflow.

## Highlights

- Local `.xlsx` import with worksheet switching for multi-sheet workbooks
- Cleaned `.xlsx` export without uploading workbook contents
- Exact duplicate-row detection after cleaning rules are applied
- Duplicate rows highlighted in the cleaned preview
- Export choice: keep every row or keep only the first exact duplicate
- Duplicate handling applies consistently to CSV, JSON and XLSX exports
- English, Traditional Chinese and Simplified Chinese UI updates
- Additional regression coverage for XLSX round trips and duplicate grouping/removal

## Privacy

All normal file parsing, cleaning, duplicate detection, previewing and exporting remain local to the browser. DataFix does not require source files to be uploaded to a server.

## Deliberate limits

- XLSX styling is not preserved when exporting a cleaned workbook
- DataFix does not evaluate Excel formulas; cached/displayed values are used when available
- Duplicate Detection v1 matches exact cleaned rows only; fuzzy matching and merge suggestions remain future work
